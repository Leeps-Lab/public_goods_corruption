  1. Puntos iniciales (dotación) {{ if ins.heterogeneous }} El ciudadano 1 recibe {{ ins.c1_endowment }} puntos. Los ciudadanos 2 y 3 reciben {{ ins.endowment }} puntos cada uno. {{ else }} Cada ciudadano recibe {{ ins.endowment }} puntos. {{ endif }} El funcionario no recibe puntos iniciales.

Contribución al proyecto del grupo {{ if ins.heterogeneous }} Cada ciudadano decide cuántos de sus puntos aporta al proyecto del grupo (el ciudadano 1, de 0 a {{ ins.c1_endowment }}; los ciudadanos 2 y 3, de 0 a {{ ins.endowment }}). {{ else }} Cada ciudadano decide cuántos de sus puntos aporta al proyecto del grupo, de 0 a {{ ins.endowment }}. {{ endif }} Los puntos que no aporta se quedan en su cuenta.     Tienes {{ ins.stage_time }} para enviar tu contribución. {{ endif }}
  4. Recursos públicos La computadora suma las contribuciones de los tres ciudadanos y multiplica el total:
    Recursos públicos totales = Suma de contribuciones × Multiplicador
    {{ if ins.random_multiplier }} En este bloque, el multiplicador se sortea al inicio de cada ronda: vale 2,5 con probabilidad 2/3 y 1,5 con probabilidad 1/3. El funcionario ve el valor sorteado desde el inicio de la ronda; los ciudadanos no lo ven cuando deciden su contribución. {{ else }} En este bloque, el multiplicador es {{ ins.multiplier }} en todas las rondas. {{ endif }}
  5. Reparto de los recursos públicos {{ if ins.allocation }} El funcionario decide cuántos puntos de los recursos públicos totales recibe cada ciudadano. Puede asignar cualquier cantidad a cada uno (incluido 0, y con hasta 1 decimal), pero debe repartir el total completo. En su pantalla, el funcionario ve el total de recursos públicos, pero no cuánto aportó cada ciudadano. {{ else }} Los recursos públicos totales se reparten en partes iguales entre los tres ciudadanos, sin importar cuánto aportó cada uno. {{ endif }}
    6. {{ if ins.audits }}
  6. Auditoría Algunos participantes pueden ser auditados. Se explica en detalle más abajo.
    7. {{ endif }}
  7. Resultados Verás un resumen de la ronda con tu pago. Luego empieza la siguiente ronda.

Interacción privada

{{ if ins.chat_only_officer }} Cada ciudadano puede comunicarse en privado con el funcionario. El funcionario puede comunicarse con los tres ciudadanos al mismo tiempo, por separado. {{ else }} Cada miembro del grupo puede comunicarse en privado con los demás miembros. {{ endif }} Hay dos herramientas:

  • Chat privado.
  • Ofrecer o solicitar puntos. Una transferencia solo se realiza si la otra persona hace clic en «Aceptar». Mientras no haya sido aceptada, quien la inició puede cancelarla.

Solo puedes entregar puntos que tengas disponibles en ese momento. Los puntos que envías o recibes se restan o suman a tu pago de la ronda. En el caso de los ciudadanos, también cambian los puntos disponibles para contribuir.

{{ if ins.audits }}
Auditorías

En cada ronda, después del reparto de los recursos públicos, cada participante puede ser auditado con una probabilidad de {{ ins.audit_pct }}%. El sorteo es independiente para cada persona y cada ronda.

  • Un ciudadano auditado recibe 0 puntos en esa ronda si se cumplen las dos condiciones siguientes:
    1. en esa ronda envió al funcionario más puntos de los que recibió de él, y
    2. recibió más recursos públicos que la parte igual (recursos públicos totales ÷ 3).
  • El funcionario auditado recibe 0 puntos en esa ronda si al menos un ciudadano de su grupo cumple las dos condiciones, aunque ese ciudadano no haya sido auditado.

Si eres auditado, lo verás en el resumen de la ronda.
